# Splendor 1.02 安装与首次同步教程

**完整体验 = PICO 头显上的 Splendor APK + 电脑 Blender 中的 Splendor 插件，两项都要安装。** 体验用户无需安装 Unity 或编译源码。

项目提供者反馈已测试的组合：**PICO 开发测试设备 + Blender 5.2 + Splendor 1.02 + Splendor 插件 3.22.0**。其他设备和 Blender 版本尚未确认兼容；设备要求请向项目提供者了解。测试范围见文末。

## 1. 下载两个必需组件

打开 [Splendor 1.02 下载页](https://github.com/pengfei2028-arch/splendor-downloads/releases/tag/v1.02)，推荐下载 `Splendor-1.02-Experience.zip`，解压后按本教程安装：

| 文件 | 用途 |
| --- | --- |
| `Splendor-1.02.apk` | 安装到 PICO 头显 |
| `MeshSyncBlender_v3.22.0.zip` | 安装到电脑上的 Blender，保留这个 ZIP，不必解压 |
| `GettingStarted.zh-CN.md` | 本教程 |
| `SHA256SUMS.txt`、`release-manifest.json` | 两个安装包的校验值及版本记录 |

下载页也提供两个安装包的单独下载。不要把整个 `Splendor-1.02-Experience.zip` 当成 Blender 插件安装。应用版本 1.02 和插件版本 3.22.0 是独立编号。

插件从 3.22.0 起改名为 **Splendor**（以前叫 `Binary-FileStream Protocol (GLB)`，面板叫 Binary-Sync）。ZIP 文件名仍是 `MeshSyncBlender_…`，这是插件文件夹的名字，没有改。

安装包与教程公开下载，无需 GitHub 账号或源码仓库访问权限。

## 2. 准备头显

1. **如果头显上装过 Splendor 1.01，先卸载它。** 1.02 和 1.01 的安装包签名不同，系统不允许直接覆盖安装。卸载会清掉头显上的校准记录和模型缓存，不影响电脑上的文件。
2. 按项目提供者给出的设备安装方式，将 `Splendor-1.02.apk` 安装到 PICO 头显。开发测试设备的安装入口以实际设备说明为准。
3. 在头显中启动 Splendor。第一次打开会出现 **Before you start** 提示，说明下面两件事；看完点 **Got it**，以后不再出现。
4. **头显和电脑连接同一个 Wi-Fi。** 有些网络（公司访客网、开了“AP 隔离”的路由器）不允许设备互访，这种网络上无法同步。

## 3. 在 Blender 5.2 安装插件

1. 打开 Blender，进入 **编辑（Edit）→ 偏好设置（Preferences）→ 插件（Add-ons）**。
2. 打开插件页右上角菜单，选择 **从磁盘安装（Install from Disk）**。
3. 选择下载的 **`MeshSyncBlender_v3.22.0.zip`**，完成安装。
4. 在插件列表搜索 **`Splendor`**，勾选启用。安装完成不等于已经启用。
5. 回到 Blender 主窗口，把鼠标放在 **3D 视图** 上，按 **N** 打开右侧边栏，选择 **Splendor** 标签。
6. 确认面板标题是 **Splendor v3.22.0**。如果关闭了偏好设置的自动保存，请手动保存偏好设置。

**从旧版插件升级**：直接按上面的步骤从磁盘安装新 ZIP 即可，会覆盖旧版。升级后原来的 Binary-Sync 标签没有了，在侧边栏点 **Splendor**。

**面板语言**：默认跟随 Blender 的界面语言（中文界面显示中文，其他显示英文）。面板标题栏右边的 **EN / 中文** 按钮可以随时切换。

## 4. 完成第一次场景同步

1. 先保存当前文件，用简单的立方体场景测试。切换到 **Object Mode（物体模式）**。
2. 确认头显上的 Splendor 正在运行。几秒内，它会出现在面板的 **头显** 区域。
   - 网络里只有一台头显时，插件会自动选中它（这一行显示为按下的样子），不用点。
   - 有几台头显时，点你要用的那一台。
   - 列表里一直没有：展开 **更多设置**，在“手动填头显地址”里填头显的局域网 IP，端口保持 **8080**。**`127.0.0.1` 指电脑自身，不能当作头显地址。**
3. 点击 **开始同步**。这会开始同步，并自动发送一次完整场景；不用先点“重新发送整个场景”，也不用先选中物体。
4. 状态行显示 **已连接，改动会自动同步** 时，在头显中查看是否出现立方体。
5. 在 Blender 中移动、旋转或缩放立方体，观察头显里的变化。先验证这个简单场景，再打开自己的项目。
6. 结束体验时点击 **停止同步**，并退出头显中的应用。

头显里也可以捏住模型移动、旋转、缩放，这些改动会写回 Blender 的场景，所以建议使用已保存的场景或副本。点 **停止同步** 之后，头显里的操作不再写回 Blender；也可以在 **更多设置** 里关掉“头显里移动模型时写回 Blender”。

## 5. 面板一览

面板只有三块，平时只用前两块：

| 区域 | 内容 |
| --- | --- |
| 头显 | 网络里听到的头显。按下样子的那一行就是“开始同步”会连的那台。右上角的刷新按钮立刻刷新列表 |
| 开始同步 / 停止同步 | 下面一行是当前状态：未开始同步、等待头显连接…、已连接。再下面是 **重新发送整个场景** |
| 更多设置（折叠） | 手动填头显地址、改动后自动同步、同步贴图、编辑模式下也同步、头显里移动模型时写回 Blender、实体视图颜色跟随基础色、多人评审、语言；最下面还有一层折叠的 **排查问题** |

**每次重新打开或切换 `.blend` 文件后，都需要再次点击“开始同步”。** 插件不会自动恢复上一个文件的同步状态。

头显重启或重新连 Wi-Fi 后地址可能变了，插件会认出是同一台头显，自动换到新地址，不用重新选。

## 6. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 安装后在插件列表里找不到 | 搜索 `Splendor` 并勾选启用 |
| 找不到 Splendor 面板 | 确认插件已启用；鼠标放在 3D 视图上按 N，在右侧边栏找 Splendor 标签 |
| 头显区域一直显示“还没发现头显” | 确认头显上的 Splendor 正在运行、两边连的是同一个 Wi-Fi；仍不行就在“更多设置”里手动填头显 IP |
| 头显安装 APK 时提示失败或冲突 | 头显上还装着 1.01，先卸载再安装 |
| 一直显示“等待头显连接…” | 检查头显应用是否在运行、网络是否允许设备互访；macOS 上如果系统询问 Blender 能否访问本地网络，请选择允许 |
| 面板提示“听见 N 台头显：点其中一台再开始” | 网络里有多台头显，点你要用的那一台 |
| 已连接但没看到模型 | 先用简单立方体排查，保持 Object Mode，再点“重新发送整个场景” |
| 打开另一个文件后不再同步 | 再次点击“开始同步” |
| 修改模型没有自动同步 | 检查“更多设置”里的“改动后自动同步”；若面板顶部提示有定时器没在跑，点击“修复” |

仍有异常时，展开 **更多设置 → 排查问题**，点 **看到异常？点这里抓现场**。诊断信息会写进插件日志文件 `MeshSyncBlender.log`，把它连同操作步骤和 Blender 版本发给项目提供者：

- Windows：`%APPDATA%\Blender Foundation\Blender\5.2\scripts\addons\MeshSyncBlender.log`
- macOS：`~/Library/Application Support/Blender/5.2/scripts/addons/MeshSyncBlender.log`

## 测试记录与参考

- 项目提供者在 PICO 开发测试设备 + Blender 5.2（Windows）上测试了与 1.02 相同源码的测试包：自动选中头显、首次同步、贴图缓存、头显里抓取模型均正常。1.02 是在这份源码上只修改版本号后重新构建的，发布前没有在设备上再安装一遍。
- 插件 3.22.0 里“停止同步后不再写回头显的操作”“头显拖动带子物体的模型时不再回发子物体”这两项修复，是在设备测试之后加入的，只在 Blender 中用模拟数据验证过。
- 插件 ZIP 在全新的 Blender 5.2 配置中从磁盘安装、启用验证通过。macOS 上的这个版本尚未测试。
- APK 使用 Android Debug 签名，APK v2 签名验证通过。

已知问题：模型里绑定在第三套 UV 上的贴图，在头显里不会按那套 UV 显示；前两套 UV 不受影响。

Blender 安装入口参考官方文档：[Blender 5.2 插件设置](https://docs.blender.org/manual/zh-hans/5.2/editors/preferences/addons.html)、[扩展与从磁盘安装](https://docs.blender.org/manual/zh-hans/5.2/editors/preferences/extensions.html)。面板名称和按钮行为依据随包提供的插件 3.22.0 源码整理。
